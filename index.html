Metric definitions (KALKULASI slide)
  • Loading Time = working hours - planned stop. Breakdown Time = sum of trouble time of machine-stop troubles. Both come from the Call System KPI sheet, in minutes.
  • IR (%) = Breakdown Time / Loading Time x 100.
  • MTTR (h) = Breakdown Time / Breakdown Frequency.
  • MTBF (h) = Loading Time / Breakdown Frequency.
  • For a period, the times and frequencies are added first, then divided. Change vs previous: the equal-length period just before; IR in percentage points.
  • Maintenance cost: the Call System 2026 file has no cost field, so it shows Unavailable.
